# examples/ — reference material new users can copy from

Worked examples for onboarding. Not loaded into the AI's working prompt — these are for humans setting the system up the first time, plus for AI to reference when explaining what "good" looks like.

## Files

| File / folder | What |
|---|---|
| `cv-example.md` | Example CV in the expected format. Copy-template for `me/cv.md`. |
| `article-digest-example.md` | Example proof-point digest. Copy-template for `me/article-digest.md`. |
| `sample-report.md` | What a finished A–G evaluation report looks like |
| `ats-normalization-test.md` | Sample showing how Unicode (em-dashes, smart quotes) get normalized for ATS |
| `dual-track-engineer-instructor/` | Worked example for a hybrid IC + educator profile (CV + profile.yml) |
| `README.md` | Index of the examples |

## When to enter

- New user onboarding → copy `cv-example.md` → `cv.md` and iterate
- You want to see what a 4.5/5 report looks like → `sample-report.md`
- You're a hybrid-role candidate → `dual-track-engineer-instructor/`

## When NOT to load

Do not load examples into the AI context during normal evaluations — they're large and irrelevant noise once the user has their own CV. Reference them by path if needed.
